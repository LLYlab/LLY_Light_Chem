# 桌面版（旧版，保留备用）

`spectrum_app.py` 是 2026-05 的初版：Tkinter 界面 + numpy + Pillow，只能在 Windows 上跑。

**新功能都在网页版**（`../web/`）：找峰、标定、元素识别、光栅常数、报告导出。
这个文件保留的原因只有一个：**没有浏览器、或需要完全离线跑批量脚本时**，它还是一条退路。

## 运行

```powershell
py -3 -m pip install numpy pillow
py -3 spectrum_app.py
```

## 与网页版的差异

| | 桌面版 | 网页版 |
|---|---|---|
| 找峰 | 平台分割 + 奇偶筛选 | 平滑 + 显著度 + 亚像素 |
| 标定 | 手动输入 a、b | 灯源自动标定 / 两点 / 二次 |
| 元素识别 | 随机枚举（不稳定） | 单调匹配 + 物理先验 |
| 光栅常数 | 无 | 有（含不确定度） |
| 报告 | 无 | PNG / 打印 |
| 平台 | Windows | 任意浏览器 |

> 结论：除非你明确需要 Tkinter，否则用网页版。
