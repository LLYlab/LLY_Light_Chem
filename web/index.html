怎么拍一张能用的光谱照片

  1. 对准狭缝：让谱线横平竖直，不要斜着拍。
  2. 别过曝：亮线周围不要糊成一片白，暗背景里能看到几条清楚的线最好。
  3. 带上标尺：如果可能，同一张图里拍到刻度或已知双线（钠双线最好）。
  4. 拍平：手机尽量与屏幕/目镜平行，避免透视变形。
  5. 多拍几张：同一组条件拍 3 张，挑最清楚的。

识别不准时，先调左侧「灵敏度 / 最小间距 / 平滑窗口」，再看「标定」里的 R²。
